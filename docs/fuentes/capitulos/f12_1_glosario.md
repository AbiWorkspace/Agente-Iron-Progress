# F12.1 — Glosario y nomenclatura

> Estado: **hecho** · Fecha: 2026-08-27

| Término | Definición |
|---|---|
| **1RM** | Repetición máxima: la carga con la que se puede completar exactamente una repetición con técnica válida. |
| **e1RM** | 1RM estimado (*estimated*), calculado a partir de una serie submáxima mediante ecuaciones de regresión (Cap. 2 §2.1.1). |
| **RPE** | *Rating of Perceived Exertion* — esfuerzo percibido, escala específica de fuerza (Cap. 2 §2.1.2). |
| **RIR** | *Reps in Reserve* — repeticiones en reserva, complementaria al RPE. |
| **MEV** | Volumen mínimo efectivo — el volumen semanal más bajo que sigue produciendo adaptación. |
| **MAV** | Volumen máximo adaptativo — el volumen semanal más alto que el atleta puede recuperar y seguir progresando. |
| **MRV** | Máximo volumen recuperable — el techo de volumen que el sistema de recuperación del atleta puede tolerar. |
| **DUP** | *Daily Undulating Periodization* — periodización ondulante diaria (Cap. 2 §2.1.4). |
| **ACWR** | *Acute:Chronic Workload Ratio* — ratio de carga aguda/crónica (Cap. 2 §2.2, Cap. 9 §9.1). |
| **EWMA** | *Exponentially Weighted Moving Average* — media móvil ponderada exponencialmente. |
| **VBT** | *Velocity-Based Training* — entrenamiento basado en velocidad (Cap. 2 §2.3, Cap. 11). |
| **MPV** | *Mean Propulsive Velocity* — velocidad media propulsiva. |
| **MVT** | *Minimum Velocity Threshold* — velocidad mínima umbral, la velocidad a la que se estima el fallo (RIR 0) para un ejercicio y nivel dados. |
| **SNC** | Sistema nervioso central — la guardia de fatiga central del motor de planificación (Cap. 8 §8.4). |
| **LLM** | *Large Language Model* — modelo de lenguaje de gran escala (Cap. 2 §2.4). |
| **RAG** | *Retrieval-Augmented Generation* — generación aumentada por recuperación (Cap. 2 §2.7). |
| **Tool calling / function calling** | Mecanismo por el que un LLM invoca funciones externas declaradas en un catálogo (Cap. 2 §2.5). |
| **Prefill** | Fase de un turno de inferencia en la que el modelo procesa el prompt de entrada completo antes de empezar a generar texto. |
| **Decode** | Fase de generación token a token de la respuesta, tras el prefill. |
| **Caché de prefijo** | Reutilización del cómputo de atención de los tokens que dos peticiones consecutivas comparten al inicio (Cap. 2 §2.4). |
| **Cuantización** | Reducción de la precisión numérica de los pesos de un modelo para reducir su huella de memoria (Cap. 2 §2.4). |
| **Webhook** | Mecanismo por el que un servicio externo (Meta) notifica al sistema de un evento (mensaje entrante) mediante una petición HTTP saliente. |
| **HMAC** | *Hash-based Message Authentication Code* — mecanismo de verificación de firma usado para validar que un webhook proviene realmente de Meta. |
